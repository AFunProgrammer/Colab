# Python Data Science Workspace

A collection of Python data science notebooks, exploratory analyses, and data processing workflows built and executed using **Google Colab**.

---

## 🚀 Why Google Colab?

This repository relies heavily on [Google Colab](https://colab.research.google.com/) for interactive code execution and experimentation. Colab provides several key advantages for data science workflows:

* **Zero Setup:** Run Python code directly in the browser without managing local environments or dependencies.
* **Free GPU/TPU Access:** Accelerate compute-heavy tasks like machine learning and large dataset manipulations.
* **Pre-installed Stack:** Comes out-of-the-box with popular data libraries (`pandas`, `NumPy`, `Matplotlib`, `Seaborn`, `scikit-learn`).
* **Cloud Persistence & Sharing:** Seamless integration with Google Drive and GitHub for version control and collaborative analysis.

---

## 🛠️ Tech Stack & Tools

* **Language:** Python 3
* **Environment:** Google Colab / Jupyter Notebooks
* **Core Libraries:**
  * `pandas` & `NumPy` – Data manipulation and numerical computing
  * `Matplotlib` & `Seaborn` – Data visualization and statistical graphics
  * `scikit-learn` – Machine learning algorithms and data preprocessing
